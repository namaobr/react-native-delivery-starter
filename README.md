# React Native Delivery Starter

Production-grade starter architecture extracted from a live social
commerce platform: auth, real-time feed, payments and push
notifications.

## Stack

React Native · Expo · TypeScript · Node.js · PostgreSQL · Supabase

## Features

- 🔐 Auth flow (Supabase)
- 📡 Real-time feed
- 💳 Payment flow (Stripe-ready)
- 🔔 Push notifications setup
- 🗺️ Delivery tracking architecture

## Live reference

A production app built on this architecture:
**usenamao.com**

## Getting started

```bash
npm install
npm start
```
